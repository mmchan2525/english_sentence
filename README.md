# 📚 Daily English 99 - 日常英会話フレーズ復習アプリ

日常会話・とっさのトラブル・感情表現・美容・食感など、厳選された **全99フレーズ** をスマートフォンやPCで効率よく復習できる学習アプリです。

リポジトリURL: [https://github.com/mmchan2525/english_sentence](https://github.com/mmchan2525/english_sentence)

---

## 🌟 主な特徴

- 📱 **スマホ最適化（モバイルファースト）**:
  単一の HTML ファイル（`index.html`）で動作し、ブラウザ（Safari / Chrome）で開くだけで即座に使えます。
- 🗣️ **ネイティブ音声再生（Web Speech API）**:
  外部通信不要で、端末の合成音声（英語ネイティブ音声）をワンタップで再生。
- 🎧 **英文1回 ➔ 日本語1回 ➔ 英文2回 の通しリスニング**:
  歩きながらや家事中に耳だけで復習できる「ながらリスニング」機能を搭載。
- 🎵 **完成版MP3ファイル付属（約24分）**:
  全99フレーズを通しで聴ける `daily_english_99_full.mp3`（8.7MB）および個別MP3（`audio_files/`）を同梱。スマホの画面をオフにした状態でも再生可能。
- 📇 **3D暗記カード（フラッシュカード）**:
  タップで表裏が回転。復習したいフレーズだけを「☆」で残せます。
- ⭐ **復習リスト管理**:
  苦手なフレーズや復習したいものだけをワンタップで☆登録し、絞り込み表示・集中リスニングが可能。
- 🔄 **「最新版を読み込む」更新ボタン**:
  画面下部にキャッシュクリア更新ボタンを設置。いつでも最新の状態で復習できます。

## 🚀 使い方

### 1. スマホでアプリを開く（GitHub Pagesを利用する場合）
リポジトリの設定（Settings ➔ Pages）で、Source を `Deploy from a branch`、Branch を `main` / `root` に設定すると、以下のURLでどこからでもアクセスできるようになります：

👉 `https://mmchan2525.github.io/english_sentence/`

> **スマホのホーム画面に追加してアプリ化する:**
> - **iPhone (Safari)**: 画面下の共有アイコン ➔ **「ホーム画面に追加」**
> - **Android (Chrome)**: 右上の「︙」 ➔ **「ホーム画面に追加」**

### 2. ローカル環境で開く場合
`index.html` をダブルクリックしてブラウザで開くか、付属の `run_phone_server.bat` を実行してご自宅のWi-Fi経由でスマホからアクセスできます。

### 3. 音声ファイル（MP3）について
- `daily_english_99_full.mp3`: 1番から99番まで通しで再生されるマスター音声（約24分13秒）
- `audio_files/`: 各フレーズ個別のMP3（01.mp3 〜 99.mp3）

## 📑 収録フレーズ カテゴリ一覧

1. **体調・汗（1〜4）**: `sweat`, `sweaty`, `sweat easily`, `cold sweat`
2. **交通・移動トラブル（5〜10）**: `missed my flight`, `opposite direction`, `missed my stop`, `wrong bus`, `ticket gate`
3. **服装・身だしなみ（11〜20）**: `inside out`, `backwards`, `buttoned up wrong`, `zipper is open`, `wrinkled`
4. **感情・気分・つぶやき（21〜30）**: `spacing out`, `slipped my mind`, `irritated`, `antsy`
5. **外見・美容・パーツ（31〜40）**: `smooth skin`, `beady eyes`, `almond eyes`, `shapely nose`, `cavity`
6. **写真撮影（41〜50）**: `blurry`, `crouch down`, `squeeze in`, `landscape mode`, `portrait mode`
7. **記憶・連想（51〜60）**: `rings a bell`, `put a face to the name`, `on the tip of my tongue`
8. **味覚・食感（61〜70）**: `crispy / fluffy`, `melts in my mouth`, `rich and thick`, `chewy`, `texture`
9. **人間関係・会話（71〜80）**: `on the same page`, `speaks ill of`, `exaggerates`, `sarcastic`, `in a roundabout way`
10. **体調・健康トラブル（81〜90）**: `hangover`, `food poisoning`, `leg cramp`, `sore`, `heat stroke`
11. **天気・気候（91〜96）**: `lovely day`, `breeze`, `shade`, `lightning struck`
12. **気遣い・日常表現（97〜99）**: `stay hydrated`, `I’ll let you go`, `Stay safe and cool!`
