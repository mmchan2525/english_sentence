# 📚 Daily Yuri's English - 日常英会話フレーズ復習アプリ

日常会話・とっさのトラブル・感情表現・美容・食感・旅行・仕事など、厳選されたフレーズをスマートフォンやPCで効率よく復習できるWeb学習アプリです。

リポジトリURL: [https://github.com/mmchan2525/english_sentence](https://github.com/mmchan2525/english_sentence)

---

## 🌟 主な特徴

- 📑 **範囲別タブ切り替え**:
  フレーズを学習しやすい単位にタブ分けしています。
  - **`1～100`**（100フレーズ）
  - **`101～200`**（100フレーズ）
  - **`201～300`**（91フレーズ）
  - **`301～`**（51フレーズ）
  - **`すべて`**（全342フレーズ）
- 🗣️ **ネイティブ音声再生（Web Speech API）**:
  端末の合成音声（英語ネイティブ音声 / 日本語音声）をワンタップで再生。
- 🎧 **英文1回 ➔ 日本語1回 ➔ 英文2回 のリスニング再生**:
  リスニングタブから、指定したタブ範囲や要復習リストのフレーズを自動で連続再生。歩きながらや家事中にも耳だけでインプットできます。
- 📇 **3D暗記カード（フラッシュカード）**:
  タブで選択した範囲のフレーズをカード形式で学習。タップで表裏反転、シャッフル、表裏言語の切り替えに対応。
- ⭐ **復習リスト管理**:
  苦手なフレーズや復習したいものだけをワンタップで「☆」登録。ヘッダーの「⭐ 復習リスト」からいつでも絞り込み・集中学習が可能。
- 🎯 **4択クイズ**:
  選択したタブ範囲から10問をランダム出題。即座に理解度をチェック。
- 🔄 **「最新版を読み込む」更新ボタン**:
  画面下部およびヘッダーにキャッシュクリア更新ボタンを設置。いつでも最新の状態で復習できます。

## 🚀 使い方

### 1. スマホでアプリを開く（GitHub Pages）
GitHub Pagesを有効にすると、以下のURLでブラウザから即座にアクセスできます：

👉 `https://mmchan2525.github.io/english_sentence/`

> **📱 スマホのホーム画面に追加してアプリ化する:**
> - **iPhone (Safari)**: 画面下の共有アイコン ➔ **「ホーム画面に追加」**
> - **Android (Chrome)**: 右上の「︙」 ➔ **「ホーム画面に追加」**

### 2. ローカル環境で開く場合
`index.html` をダブルクリックしてブラウザで開くか、付属の `run_phone_server.bat` を実行してご自宅のWi-Fi経由でスマホからアクセスできます。
